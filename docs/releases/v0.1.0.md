# HelloBoard v0.1.0

HelloBoard 首个发行版，提供系统状态、进程管理与可选 WiFi / AP 管理，以及包含独立 Python 运行环境的 Ubuntu amd64 离线安装包。

## 功能与布局

- 系统状态：CPU、各核心占用、内存、存储、网卡流量及设备支持的温度等指标；共享最近十分钟趋势历史。
- 进程管理：搜索、排序、多选与经过系统账号验证的终止操作，保护关键进程。
- WiFi 管理：连接、扫描、保存网络与 AP 热点设置，按系统和网卡能力开放。
- 桌面四栏紧凑布局与两栏宽松布局，手机自适应；中英文、深浅色、柔和动效与本地字体。

## 轻量化

使用 Flask、Waitress 与原生 HTML / CSS / JavaScript，无需 Node.js、数据库或外部 CDN。后台共享采样，界面复用数据节点，静态资源启动预压缩并按版本缓存；保留六个 HTTP 工作线程与完整中英文字体。

现有测试设备上，首次静态资源传输量从 614 KiB 降至 298 KiB，模拟慢 WiFi 首次加载从 2.90 秒降至 2.02 秒；常用负载后 RSS 从 40.8 MiB 降至 39.6 MiB。以上是特定设备与测试条件下的结果，不代表所有电脑的实际表现。

## Ubuntu x86_64 安装

适用于使用 systemd 的 Ubuntu 20.04 及更新版本、Intel / AMD 64 位处理器。deb 内置 Python 3.13.17、全部 Python 运行依赖和完整字体，安装时不运行 pip，也不下载 Python 包。基础 glibc、PAM 和 systemd 使用目标 Ubuntu 系统提供的组件。

安装包约 28.5 MiB；建议为程序预留至少 150 MiB，安装时还需临时空间。

```bash
curl -fL --retry 3 \
  'https://gitee.com/gcusms/helloboard/releases/download/v0.1.0/helloboard_0.1.0-1_amd64.deb' \
  -o helloboard_0.1.0-1_amd64.deb

curl -fL --retry 3 \
  'https://gitee.com/gcusms/helloboard/releases/download/v0.1.0/helloboard_0.1.0-1_amd64.deb.sha256' \
  -o helloboard_0.1.0-1_amd64.deb.sha256

sha256sum -c helloboard_0.1.0-1_amd64.deb.sha256
sudo dpkg -i ./helloboard_0.1.0-1_amd64.deb
```

安装后服务自动启动并设置开机自启，默认访问 `http://设备IP/`（端口 80）。默认仅启动系统看板，不接管目标电脑现有网络。

服务参数：`/etc/default/helloboard`；网络配置：`/etc/helloboard/wifi.yaml`。启用 WiFi 管理需要 NetworkManager、兼容网卡和相应权限；先填写网络配置，再删除启动参数中的 `--dashboard-only` 并重启服务。AP 功能另需网卡支持与 dnsmasq-base。
